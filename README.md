# E-Portofolio PPL Mandiri – Erwin Fajariansyah

E-portofolio PPL Mandiri PPG Calon Guru Informatika, Universitas Muhammadiyah Surakarta, kelas XII SMA Negeri 1 Colomadu.

## Isi folder

| Folder / berkas | Isi |
|---|---|
| `index.html` | Halaman portofolio |
| `berkas/dokumen/` | Modul ajar, slide presentasi, LKPD, dan lembar penilaian (PDF) |
| `berkas/foto/` | Foto diri dan dokumentasi kegiatan |
| `berkas/video/` | Video dokumentasi pembelajaran |
| `lib/pdfjs/` | Pustaka penampil PDF (pdf.js, lisensi Apache 2.0) |

Semua tautan di `index.html` mengarah ke folder `berkas/`, jadi susunan folder ini jangan diubah atau dipindah.

## Cara menayangkan di GitHub Pages

1. Buat repository baru di GitHub, misalnya `eportofolio-erwin`, dengan visibilitas **Public**.
2. Klik **Add file → Upload files**, lalu seret **isi** folder ini (`index.html`, folder `berkas`, folder `lib`, dan `README.md`), bukan folder induknya. Klik **Commit changes**.
3. Buka **Settings → Pages**. Pada *Build and deployment*, pilih **Deploy from a branch**, branch **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu 1–2 menit. Alamat portofolio muncul di bagian atas halaman Settings → Pages, misalnya `https://namapengguna.github.io/eportofolio-erwin/`.

Catatan: tombol **Edit halaman** hanya ada di versi Claude. Untuk mengubah isi, edit di Claude lalu ekspor ulang, atau ubah langsung bagian data di `index.html`.
